\# llm-starter



My first program that calls an LLM.



\## Setup



1\. Clone this repository and open the folder.

2\. Create a virtual environment: `python -m venv .venv`

3\. Activate it:

&#x20;  - Windows: `.venv\\\\Scripts\\\\Activate.ps1`

&#x20;  - macOS/Linux: `source .venv/bin/activate`

4\. Install packages: `pip install -r requirements.txt`

5\. Copy `.env.example` to `.env` and add your API key.

6\. Run: `python hello\\\_llm.py`
